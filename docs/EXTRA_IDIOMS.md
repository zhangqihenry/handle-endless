# 词库维护与随机规则

| 词库 | 用途 | 可修改性 |
| --- | --- | --- |
| 官方每日库 | 每日题目、历史题目、随机候选 | 只读，保留官方答案表 |
| 官方普通成语库 | 严格模式输入校验与拼音处理 | 支持添加、编辑、删除 |
| 扩展库 | 增加随机候选，并允许严格模式输入新增词语 | 支持添加、编辑、删除 |

随机候选为官方每日库与扩展库的合集，按固定顺序去重排序，普通库不会整体加入随机候选。

## 在管理页面维护

打开 `/admin`，默认密码 `handleendlessadmin123`。

普通库每页可选 50、100、250、500 或 1000 条，调整后回到第一页，并记住选择。搜索和翻页继续使用所选数量。

普通库中，每条成语均提供编辑、删除和“添加至扩展库”勾选按钮。选中立即加入扩展库，取消立即从扩展库移除。与每日库重合的词标注“每日库已有”，并禁用扩展勾选，避免重复添加。

编辑已选入扩展库的普通词条时，成语和读音会同时更新到扩展库。改名若与其他普通词或扩展词冲突，后台会提示；新增普通词不会自动选入扩展库。删除普通词不会删除其他库中的同名词，确认框会明确说明。新增、改名及去重均先将繁体转换为简体。同一成语的繁简变体共用修改记录；未编辑的原始词条保持原样展示。

普通库修改用于游戏的输入校验和读音。每日库重合词在游戏中始终保留官方读音和可输入状态，即使普通库同名条目被修改或删除，也不影响每日题目和每日候选。

扩展库也可直接添加、编辑或删除：

- 官方每日库已经有的词会被拒绝，保存时后台再次检查。
- 普通库已有的词自动采用当前普通库读音。如需调整，请在普通库编辑。
- 新词请填写四个用空格分隔的拼音，声调用数字 1 至 5，轻声用 5，ü 用 v，例如 `chun1 he2 jing3 ming2`。多音字读音请人工核对。

所有修改检查修订号，避免多页面互相覆盖。普通库和扩展库通过同一次文件原子替换保存，编辑同步过程中不会只写入其中一个库。刷新游戏后生效，已打开的题目不会中途变化。

## 文件、迁移与备份

NAS 的 `data/library-state.json` 保存普通库修改记录 `ordinaryOverrides` 和扩展词条 `extra`。普通库以官方原始目录为基础，修改记录中的 `null` 表示删除，词条对象表示新增或修改。官方源文件保留作为初始目录。

v0.2.0 升级时自动将 `data/extra-idioms.json` 导入新文件，旧文件保留作迁移备份。迁移完成后，旧文件不再用于读取后续修改。管理页面始终读取新文件。

请通过管理页面维护，备份整个 `data` 目录。`admin-auth.json` 保存管理密码的加盐哈希，请不要发布到 GitHub。新安装包不含本地管理密码及自定义词库。

## 种子与版本

同一词库版本、同一数字种子得到同一道题。种子号为 1 至 64 位数字，保留前导零；不同种子可能抽到同一道题。

扩展库增删词条或修改读音会改变随机词库版本。分享链接携带版本，版本不匹配时明确提示。仅修改未加入扩展库的普通词，不改变随机候选及版本。

每日题目仅依赖官方答案表与原算法，维护普通库和扩展库不会改变每日答案。
